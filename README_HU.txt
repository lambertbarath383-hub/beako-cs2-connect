BEAKO CS2 CSATLAKOZÁSI OLDAL – INGYENES GITHUB PAGES

1. Jelentkezz be a https://github.com oldalra, vagy hozz létre ingyenes fiókot.
2. Hozz létre egy új, PUBLIC repository-t. Például a neve: beako-cs2-connect
3. Töltsd fel az index.html fájlt a repository gyökerébe (ne almappába).
4. A repository-ban menj: Settings -> Pages.
5. A Build and deployment résznél válaszd: Deploy from a branch.
6. Branch: main, mappa: /(root), majd Save.
7. Várj néhány percet. A GitHub Pages címed ilyen formájú lesz:
   https://FELHASZNALONEV.github.io/beako-cs2-connect/
